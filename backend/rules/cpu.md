# CPU Domain Knowledge

## Sockets
| Family | Socket | RAM | Notes |
|---|---|---|---|
| Ryzen 1000–5000 | AM4 | DDR4 | Budget sweet spot |
| Ryzen 7000–9000 | AM5 | DDR5 only | Current platform |
| Intel Core 12–14th | LGA1700 | DDR4/DDR5 | |
| Intel Core Ultra 200S | LGA1851 | DDR5 only | |

## TDP estimation (when not stated in name)
- Ryzen 3 / i3, non-X 5000 series: 65W
- Ryzen 5 / i5 mid tiers: 65W
- Ryzen 7 / i7, X-series: 105W
- Ryzen 9 / i9 / X3D: 125W+

## Use-case guidance
- Gaming: prioritize GPU budget over CPU
- Video editing / 3D render: core count and RAM matter more
- Office/general: 6-core class is sufficient
