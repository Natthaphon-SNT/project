# RAM Domain Knowledge

## Detection from names
- `DDR4` / `DDR5` generation token is always present in Thai retail listings
- Capacity: `8GB`, `16GB`, `32GB` (sometimes `8GB (8x1)` style)
- Speed: `3200MHz` / `3600MHz` / `5200MHz` etc.

## Guidance
- Minimum viable: 16GB for gaming/work in 2025+
- DDR4 kits are cheaper; only pair with DDR4-capable boards
- Mixing generations is physically impossible (notch position differs)
