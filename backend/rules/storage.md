# Storage Domain Knowledge

## Detection from names
- `M.2` prefix + `NVMe`/`PCIe` → NVMe SSD
- `SATA` keyword or 2.5" listing → SATA SSD
- Capacity tokens: `256GB`, `512GB`, `500GB`, `1TB`, `2TB`

## Guidance
- 2025+ baseline: 512GB NVMe minimum, 1TB preferred for gaming
- All modern boards have at least one M.2 NVMe slot — interface mismatch is rare
